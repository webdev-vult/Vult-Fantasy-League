# Vult Fantasy Platform

A reusable multi-season fantasy competition platform for Vult.

## Status

Project foundation in progress.

## Planned stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase PostgreSQL, Auth, Storage and Edge Functions
- Vercel hosting
- GitHub pull-request workflow

## Product direction

The platform is designed to support multiple competitions and seasons, beginning with the Vult EPL Fantasy League 2026/27.
